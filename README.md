## 🚀 Featured Project — DocuChunk

**Production-shape RAG & Agentic Document-Intelligence Platform**
> `Python` · `FastAPI` · `LangChain (LCEL)` · `LlamaIndex` · `pgvector / ChromaDB / Pinecone` · `Redis` · `Docker`

An end-to-end Retrieval-Augmented Generation platform (**16K LOC, 510 passing tests**)
built to be measured, not just demoed — every headline number is produced by a
committed evaluation harness.

- 🔍 &nbsp;**Hybrid retrieval** — dense vectors + BM25 + Reciprocal Rank Fusion + cross-encoder reranking → **MRR 0.78 → 0.97** on a 42-doc distractor benchmark
- 🗄️ &nbsp;**Pluggable vector storage** across **pgvector, ChromaDB & Pinecone** behind one interface — per-document routing + cross-backend query merge, with consistency/latency trade-offs quantified
- 🤖 &nbsp;**Agentic ReAct loop** — tool-use + 5 guardrails (step cap, loop detection, fallback-to-RAG); **+0.43 context-recall** over vanilla RAG under scarce budgets
- ✅ &nbsp;**LLM verification layer** — citation validation, groundedness checks & abstention; **faithfulness 0.71 → 0.89**, and it **fails closed** so a verifier outage never surfaces as a confident answer
- 📊 &nbsp;**RAGAS-aligned evaluation** + hermetic **CI regression gate**, **Langfuse tracing** (21 span types), and **per-query cost attribution** (~₹0.09/query)
- 🔌 &nbsp;**4 LLM providers** (Gemini, OpenAI-compatible, Ollama, deterministic stub) behind a protocol, with SSE streaming & semantic caching
